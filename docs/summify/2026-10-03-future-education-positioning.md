## 1. Görseldeki sistemin ihtiyaçları (özümsenmiş)

Tez kabul edilirse, “eğitim = AI” sisteminin zorunlu parçaları:

| İhtiyaç | Ne demek | Summify 2.0’da karşılığı |
|---------|----------|---------------------------|
| Bireysel seviye modeli | Her öğrenenin ne bildiği / bilmediği | User knowledge state |
| Boşluk + yanlış anlama | Eksik + misconception | Diagnose + Detect misconception |
| Öğrenme stili / açıklama modeli | Aynı bilgi, farklı biliş | Explain Like… + compression levels |
| Yaş değil yetkinlik | Mastery progression | Agent + retest + spaced repetition |
| Kaynak-temelli güven | Halüsinasyon ≠ müfredat | Source-grounded graph + evidence |
| Evden / asenkron | Okul binası şart değil | Upload anything + audio/video tutor |
| Ölçüm | “Öğrendi mi?” | Exam simulator + progress |
| Hafıza | Unutmayı yönet | Spaced repetition + Personal KB |

**Sonuç:** Görseldeki gelecek, 2.0’daki `Understand → Connect → Teach → Test → Remember → Apply` hattının **pazar tezi**; 2.0 ise **ürün mimarisi**.

## 2. Çelişki analizi (2.0 vs gelecek tezi)

### Çelişmez

- “AI tool değil, AI = eğitim” ↔ “Don’t just summarize it. Understand it.”
- Sınıf hızı yerine bireysel tempo ↔ Diagnose → Teach → Retest
- Yaş bazlı sınıfın erimesi ↔ prerequisite + mastery, not grade level
- Okul alışkanlığının kırılması ↔ personal knowledge agent (haftalık plan)

Madde 28’deki stratejik karar (“daha fazla output formatı yetmez; understanding representation şart”) tam olarak bu gelecek sistemin çekirdeği.

### Soft çelişki / risk (narrative, ürün değil)

| Tez dili | Problem | Fon / SV dili |
|----------|---------|----------------|
| “10 yılda okul/öğretmen yok” | Spekülatif, politik, anti-teacher; VC + edtech alıcıyı korkutur | “One-size-fits-all classroom kırılıyor; kişisel mastery OS yükseliyor” |
| “Okulları kapatıyoruz” | Regülasyon, ebeveyn, B2B okul satışını öldürür | “Okul / ev / kurum yanında çalışan understanding layer” |
| Tamamen evden eğitim | Sosyal/çocuk koruma boşluğu | Hybrid: ev + kurum; ürün bireysel öğrenme motoru |

**Ürün çelişkisi yok. Pitch çelişkisi var** — gelecek tezini *iç thesis* olarak tut, dışarıda *kategori trendi* olarak yumuşat.

## 3. Fonlanabilir konumlandırma (Dunford zinciri)

**Alternatif (yoksa ne yaparlar?):** ChatGPT Study Mode, NotebookLM, Notion AI, Quizlet, Khanmigo, pdf’i kendin özetle.

**Unique (bugün + 2.0):**  
Any source → durable knowledge representation → **user knowledge model** → adaptive teach/test/reteach — tek pipeline.

**Value:** “Yüklediğin materyali *senin için* anlaşılan, ölçülen, hatırlanan bilgiye çevirir.”

**Kim çok umursar?**  
1) Yoğun kaynak tüketen öğrenciler (üniversite + sınav)  
2) Self-taught profesyoneller (paper/YouTube → mastery)  
3) Sonra Team / kurumsal knowledge

**Kategori (önerilen):**  
- Kısa vadede: *AI study / understanding workspace* (mevcut SEO ile uyumlu)  
- Orta vadede: *AI Understanding Engine* / *Personal Learning OS*  
- **Yapma:** “School replacement platform” kategorisi

**Trend (görsel):** Kişiselleştirilmiş AI öğrenme; sınıfın tek hızının bitişi — **evet, trend olarak kullan**.

### Pitch cümlesi (fon)

> Summify is the understanding engine for any source: we don’t just summarize PDFs and lectures — we build a knowledge graph and a model of what *you* know, then teach, test, and rememorize until mastery.

## 4. Eğitim + AI’da gerçek boşluk (odak burası)

Pazar dolu: summarizer, chat tutor, curriculum tutor (Knowunity, Medly, Khanmigo), NotebookLM (source chat).

**Hâlâ seyrek / fonlanabilir boşluk:**

1. **Source-owned + learner-owned çift graph**  
   Materyalin KG’si *ve* kullanıcının mastery state’i — ChatGPT’te yok; NotebookLM’de zayıf/kalıcı değil; Khanmigo kendi müfredatına kilitli.

2. **Misconception detection** (doğru cevap yanlış gerekçe)  
   Pedagojik olarak zor; 2.0’da yazılmış; az rakip ciddi yapıyor.

3. **Any-material → mastery** (müfredat kataloğu değil)  
   Knowunity peer content; Medly exam board. Summify: *kullanıcının yüklediği her şey*. Bu, “okul sonrası / yaşam boyu / research” için daha geniş TAM ve SV hikâyesine uyuyor.

4. **Cross-source synthesis** (consensus / contradiction / evidence)  
   Research + debate; summarizer’dan ayrışır.

**Odak sırası (fon + büyüme):**  
Q1 killer 7’den ilk 4’ü yeterli ve doğru: **Tutor + KG + Exam + Adaptive/Memory**. Video/Battle/Public Pages dağıtım; çekirdek değil.
